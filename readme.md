# FuckLang
A bad programming language

### Why
I was bored and wanted to learn making a language so I made it. It's poorly made but at least it works

### Syntax
Its syntax is easy:

no "s required, no types. Printing Hello World:

```print Hello World```

**Variables:**

To make a variable, simply use set:

```set testing Hello world```

And to read it you can just use get:

```get testing```

It should print Hello world
